# タブと自動保存

## タブ (Excel のシート見出し)

窓の下に、開いている文書を Excel のシート見出しと同じ形で並べる。

**1 枚のタブ = 1 つの .docx。** Excel のシートは 1 つのファイルの中の部品だが、
.docx には「1 ファイルに複数の本文」という形が無い。無理に詰めると Word で開けなくなり、
Wowd の存在理由 (Word と行き来できること) が崩れる。
そこで見た目と操作は Excel のシート見出しに寄せ、中身は別々のファイルにした。

| 操作 | 動き |
|---|---|
| クリック | そのタブへ移る |
| ＋ | 新しいタブ (白紙) |
| ダブルクリック | 名前を変える。未保存の文書だけ (保存済みはファイル名そのもの) |
| 右クリック | 新しいタブ・名前の変更・名前を付けて保存・タブの色・閉じる・ほかを閉じる |
| ドラッグ | 並べ替え |
| × / 中ボタン | 閉じる。未保存なら確かめる |
| Ctrl+PageDown / PageUp | 次 / 前のタブ。端からは反対側へ回る |

Excel に無いものを 2 つ足した。各タブの **×** と、未保存の印 **●**。
Excel のシートはファイルの一部なので閉じる概念が無いが、こちらは 1 枚が 1 ファイルなので要る。

### 開く・新規の振る舞い

- 「新規」も「開く」も**新しいタブ**に開く。いまの文書を閉じさせない
- すでに開いているファイルを開くと、そのタブへ移るだけ (二重に開かない。Excel と同じ)
- いまのタブが手つかずの白紙なら、そこに開く (白紙のタブを残さない)
- 最後の 1 枚を閉じると白紙に戻る。0 枚にはしない (Excel もシートを 0 枚にできない)
- 未保存の文書は「文書1」「文書2」…と通し番号で呼ぶ。保存するときの既定の名前にもなる

### 作り

画面に出ている文書は、これまでどおり `useDocumentStore` が持つ。
リボンも印刷もコメント欄も、そこだけを見ればよい。裏に回したタブは
`useTabsStore` の `parked` に**丸ごと預ける**。切り替えは「預ける → 戻す」の 2 手で済む。

預けるときは、エディタの状態 (元に戻す履歴・選択位置) とスクロール位置も一緒に預ける。
内容だけ預けて作り直すと、タブを行き来しただけで「元に戻す」が効かなくなる。

**預ける直前に、エディタから最新の本文を拾う。**
ストアの `document.doc` は保存したときにしか更新されない (打鍵のたびに全文を変換すると重い)。
拾わずに預けると、切り替えた瞬間に編集が消える。

### 閉じるときの確認

終了の確認は**裏に回したタブの未保存も数える**。表の文書だけ見ていると、
裏のタブの編集を黙って捨てて終了してしまう。

### 退避 (落ちたときの控え)

開いているタブ**すべて**について取る。表の文書だけ退避していると、
3 枚開いて 2 枚目を編集中に落ちると、1 枚目と 3 枚目の編集が消える。

退避の枠はタブごとに分ける (`untitled-t3` など)。分けないと「無題」同士が上書きし合う。
枠の名前は renderer から渡すが、実際の保存先は main 側が決める (renderer にパスを組ませない)。
復元は 1 件ずつ別のタブに開く。

## 自動保存

Office の「自動保存」に当たる。窓の左上で切り替える (スマホは「⋮」の中)。

| | 退避 | 自動保存 |
|---|---|---|
| 書き先 | アプリの控えの場所 | **利用者のファイルそのもの** |
| いつ | 30 秒ごと | 打つのが止まって 2 秒後。止まらなくても 30 秒で |
| 既定 | 常にオン | **オフ** |

**既定はオフ。** Office も手元のファイルではオフが既定。
相手方から届いた書面を開いて眺めるつもりが、うっかり打った 1 文字で原本が書き換わる、
ということを既定では起こさない。設定は覚えるので、一度オンにすれば次からもオン。

### 書かないとき

| 状態 | 表示 |
|---|---|
| 無題 (保存場所が無い) | 保存すると自動保存が始まります |
| ブラウザ版で、保存先の持ち手が無い | この場所には自動保存できません |
| 表示に失敗して保存を止めている | 保存できませんでした |

無題の文書でオンにしたときは、その場で保存場所を尋ねる (Office と同じ)。

ブラウザ版では、保存先の「持ち手」(File System Access の handle) を得たファイルにだけ書く。
持ち手が無いファイルに書くとダウンロードになり、自動保存のたびにファイルが積み上がる。
PC の Chrome / Edge では、開くときにも持ち手を得る (`showOpenFilePicker`) ので、
開いたファイルへそのまま自動保存できる。スマホのブラウザにはこの仕組みが無い。

### タブとの関係

打ってすぐ別のタブへ移っても、裏に回したタブを**待たずにその場で書く**。
裏のタブはもう編集されないので待つ理由が無い。

### 保存中の打鍵を失わない

保存は非同期で、書き出している間も打てる。以前は保存が終わると無条件に
「未保存」の印を下ろしていたので、その間の打鍵は保存済み扱いになり、
次の保存まで誰も書かず、閉じるときの確認も出ずに失われた。
手動保存では稀だが、自動保存は数秒おきに書くので実際に起きる。

変更の通し番号 (`revision`) を持ち、保存の前後で変わっていたら印を残す。
そのときは中身 (`document`) も書き出し開始時の写しで上書きしない。
上書きすると、その間に足したコメントなどが消える。
`tests/unit/saveRace.test.ts` がこれを見ている (直す前のコードでは落ちることを確認済み)。
