# 岡口マクロ

岡口基一氏の Word マクロ「岡口マクロ」(win 版 2020/05/31) の機能を、Wowd に組み込んだもの。
**マクロ (VBA) は実行していない。** 中身を読んで、同じ結果を Wowd の機能として作り直した。

## なぜ実行せずに作り直したか

- Wowd は Word ではないので、VBA を動かす仕組みが無い
- 仮に動かせても、文書に入ったマクロを実行するのは危険 (マクロウイルスの入口になる)。
  Wowd は受け取った .docx / .docm を「危ないかもしれない入力」として扱い、マクロは開かない
- 受け取った `.docm` は、マクロを Word の Normal.dotm に登録するための**インストーラ**だった。
  開いただけで動く仕掛け (AutoOpen) は無い。2 つのボタン (Normal に保存 / Normal から削除) で登録・削除する

作り直したので、**Wowd で作った文書を Word で開いても同じに見える** (番号はスタイルと番号定義、
均等割り付けは w:fitText と、どれも Word の標準の形で保存する)。逆に、Word で岡口マクロを使って作った
文書を Wowd で開いても、ランクの番号はそのまま出る (スタイルを名前で見つける)。

## キー

元のマクロと同じキー。リボンの「岡口マクロ」タブにも同じボタンがある (スマホは「⋮」メニュー)。

| キー | 機能 |
|---|---|
| Alt+R | 連番ランク設定 (スタイル「本文０〜８」「ランク１〜８」と番号を用意する) |
| Alt+1〜8 | ランクN ⇔ 本文N の切り替え (未設定なら自動で設定する) |
| Alt+Shift+1〜8 | ランクN にして番号を 1 から振り直す (打直) |
| Alt+Shift+R | 連番ランク修正 (ランク１・２で 10 以上になった番号を半角に。第１０ → 第10) |
| Alt+J | 連番等事後設定 (手で打った「第１」「１」「（１）」などを連番ランクに置き換える) |
| Alt+P | 書式変更 (裁判所書式: A4・余白 35/25/30/20 mm・37 字 × 26 行・12pt・ページ番号) |
| Alt+T | 日付入力 |
| Alt+Z | 全角1文字入力 ((1) (a) (ｱ) を全角 1 字分の幅に) |
| Alt+M | 当事者欄作成 (自然人・代理人) |
| Alt+K | 当事者欄作成 (法人) |
| Alt+C | 利息・日付計算 |
| Alt+B | 物件情報入力 (物件目録) |

Windows では Alt+R がメニューの「校閲(&R)」と重なるが、文書の編集中は岡口マクロが優先する。

### 連番ランク

| ランク | 番号 | | ランク | 番号 |
|---|---|---|---|---|
| 1 | 第１ | | 5 | (ア) (横幅 50%) |
| 2 | １ | | 6 | a |
| 3 | ⑴ | | 7 | (a) (横幅 66%) |
| 4 | ア | | 8 | ① |

番号は右揃えで、番号と見出しの間は全角スペース (本文の文字として入る)。
上のランクが出ると下のランクは 1 に戻る。番号は本文の文字ではないので、段落を足したり消したりすると自動で振り直される。

## 元のマクロとの違い

元のマクロの不具合と思われるところは直した。元の動きに合わせたほうがよいものがあれば教えてほしい。

| 機能 | 元のマクロ | Wowd |
|---|---|---|
| 休日 (日付入力・利息) | 2020・2021 年の五輪の移動が無い、1966〜1995 年の体育の日が無い、振替休日は「翌日が月曜」だけ | 祝日法どおりに求める (振替休日・国民の休日を含む) |
| 和暦 | OS の和暦に頼り、令和を後から補正 | 日付で元号を決める |
| 日付入力 (半角) | 休日名のカナまで半角 (ｽﾎﾟｰﾂの日) | カナはそのまま |
| 利息: 2/29 起算 | 平年に終わると端数が 0 になり、利息が少なくなる | 民法 143 条どおり (応当日が無ければ月末) |
| 利息: 終了日 | 「5/1」と 3 字で入れると読めない | 読める |
| 利息: 計算式 | 92 日と 90 日が「9290日」と表示される | 正しく表示 |
| 利息: 半角で入力 | 通算日数と計算式が抜ける | 抜けない |
| 利息: 四捨五入 | 偶数丸め (0.5 円ちょうどは切り捨て) | 四捨五入 |
| 利息: 利率の空欄 | 一律 5% | 2020/4/1 以降の開始日なら 3% (法定利率)、それより前は 5% |
| 当事者欄: 6s | 「上記6６名」 | 上記６名 |
| 当事者欄: 本籍 | 「同」を受け付けない、短い本籍 (東京都港区) が「国籍」になる | 「同」も可、都道府県を含めば本籍 |
| 当事者欄: 生年月日 | 小文字の元号記号だけ | 大文字・西暦も可 (和暦で出す) |
| 物件: 床面積 | 5・6 階に 4 階の面積が出る | 正しく出る |
| 物件: ㎡ | 一棟の建物 (1 階だけ)・敷地権の地積に付かない | 付ける |
| 事後設定 | 10 以上の番号・⑵ 以降を見つけられない、ン・⑳ を超えると止まる | 見つける・止まらない |
| ランクN | 選択位置がずれる、未設定だと全角スペースだけ消える | ずれない、未設定なら自動で設定 |

### そのままにしたもの

- 当事者欄の地位で `j` だけを入れると「事件本人」(元の表どおり。上告人は `jsb` のように続けて入れる)
- 本文１と本文２、ランク１とランク２の字下げが同じ (元の値どおり)
- 物件の見出しの幅そろえは、元は横幅を変えた空白だったが、均等割り付け (w:fitText) にした。見た目は同じで、Word でもそろう

### 無いもの

- **代理人情報入力 (Alt+A)**: 元のマクロがこのフォームを呼ぶが、ファイルに入っていなかった
- **契約書モード (ContractYN) と条項 (Alt+X など)**: 別のマクロ集「岡口マクロ条項」の機能で、このファイルには無い
- **行番号の画面表示**: 書式変更で行番号を付けると、保存した文書を Word で開いたときに表示される。Wowd の画面には出ない

## 作り

| 場所 | 中身 |
|---|---|

| `src/core/okaguchi/postSet.ts` | 事後設定 (手打ちの見出し符号の検出) |
| `src/core/okaguchi/dates.ts` | 日付の読み取り・和暦・休日・日付入力の出力 |

| `src/core/okaguchi/property.ts` | 物件目録 |

| `src/renderer/okaguchi/` | キー、段落の操作、入力画面 |

あわせて直した Wowd 側の不具合:

- 段落スタイル経由の番号 (Word で見出しに番号を結び付けた文書) が画面にも PDF にも出なかった
- 印刷 (PDF) で番号がページごとに 1 に戻っていた
- 文字の横幅 (w:w) が画面で効いていなかった (inline の箱には transform が効かない)
- 均等割り付け (w:fitText) を読み込んでも表示していなかった
- 画像とコメントを同じ保存で足すと、関係 (.rels) の片方が消えることがあった
