# Word に合わせた画面と操作

Word を使ってきた人が迷わないよう、置き場所・名前・キーを Word に合わせた。

## リボン

| タブ | 足したもの |
|---|---|
| **ファイル** (左端) | 新規 (A4 / B5)・開く・最近使ったファイル・上書き保存・名前を付けて保存・印刷 / PDF・情報 (保存場所を開く)・閉じる |
| ホーム | **クリップボード** (貼り付け・切り取り・コピー・書式のコピー/貼り付け)、フォントサイズの拡大・縮小 (A▲ A▼)、**段落…** (ダイアログ)、置換・ジャンプ |
| 挿入 | リンク (Ctrl+K)、記号と特殊文字 |
| 表示 | ナビゲーション ウィンドウ |

フォントサイズの欄は、大きさの指定が無い文字でも実際の大きさ (スタイル由来) を出す。
以前は「(既定)」と出ていて、何ポイントなのか分からなかった。

## 書式のコピー / 貼り付け (ブラシ)

- 1 回押す: 今の位置の書式を写し取る。次に選んだ文字に当てて終わる
- ダブルクリック: Esc を押すまで何か所にも当てられる
- 選ばずにクリックしたときは、その語に当てる (Word と同じ)
- カーソルだけ置いて写したとき、または段落まるごと選んで写したときは、段落書式 (スタイル・配置・字下げ・間隔) も写す
- リンク・コメント・変更履歴の印は写さない (書式ではなく中身なので)

## 段落ダイアログ

インデントは**字**、段落の前後は**行**で指定する (日本語版 Word の既定の単位)。
w:leftChars / w:beforeLines などの文字・行単位で保存するので、Word で開いても同じ値が出る。
**変えた項目だけ**を、選んでいる段落すべてに当てる。触っていない項目は段落ごとの値のまま。

## 右クリックメニュー

切り取り・コピー・貼り付け、書式のコピー、段落…、リンク (編集・解除)、新しいコメント、
表の中では行・列の挿入と削除・セルの結合と分割、記号と特殊文字。
選択の外で右クリックしたらその位置へカーソルを移す (Word と同じ)。

ボタンや右クリックからの貼り付けは、アプリ版では main が自分の画面に「貼り付け」を行う
(操作の種類だけを渡し、クリップボードの中身は渡さない)。
ブラウザ版はページから貼り付けを起こせないので、文字の読み取りを試み、許されなければ Ctrl+V を案内する。

## ナビゲーション ウィンドウ

アウトライン レベルのある段落 (見出しスタイル、岡口マクロのランクなど) を左に並べ、押すとそこへ移る。
今カーソルのある節を強調する。開閉は覚える。

## ハイパーリンク

行き先は Word と同じく関係 (.rels、TargetMode="External") に入れ、本文には r:id だけを書く。
受け付けるのは https:// / http:// / mailto: と、www. で始まるもの (https:// を補う)・メールアドレス。
**Wowd の画面ではリンクを踏ませない** (受け取った文書のリンクを誤って開かないため)。行き先はマウスを載せると出る。

## 次の段落のスタイル

段落の終わりで Enter を押すと、次の段落はそのスタイルの「次の段落のスタイル」になる。
見出し 1 → 標準、岡口マクロのランク１ → 本文１。新しい段落は字下げ・配置・番号を持ち越さない。
段落の途中で Enter を押したとき (段落を割るとき) は同じスタイルのまま (Word と同じ)。

## そのほか

- ジャンプ (Ctrl+G): ページ番号 (+2 / -1 で前後) か見出しを選んで移る
- 記号と特殊文字: ※ 〒 ① ㈱ § など。最近使った記号を先頭に出す
- 文字カウント: ステータスバーの文字数を押すと開く。ページ数・単語数・文字数 (空白の有無)・段落数。選んでいればその範囲
- Ctrl+Q は段落書式の解除。そのためアプリ版の終了を Alt+F4 にした (Linux の既定は Ctrl+Q だった)
